# hxyfront-62012 热定型机位放行台

纺织染整热定型工序的机位放行管理台（由“纺织染整小样管理”页扩展）。规则、存档、界面各自独立成文件：

| 文件 | 职责 |
| --- | --- |
| `src/rules.ts` | 规则层（纯函数）：判定阈值、返工闸门、放行判定、事件归约、机位/队列/状态派生 |
| `src/archive.ts` | 存档层：事件溯源 + localStorage 持久化、登记/复测/放行/工艺更正操作、跨标签页同步、演示数据 |
| `src/App.tsx` | 界面层：机位看板、小样登记、工单详情、复测、放行、工艺更正、退回原稿、操作履历 |

## 业务规则

- 同一小样只占一台机；重复或并发登记沿用最早结果，不新建、不覆盖。
- 登记必填温度、车速、标准/实测门幅、纬斜、手感；任一缺项整单退回，不占机，原稿保留。
- 门幅偏差 > 2%、纬斜 > 3cm 或手感 < 3 级：继续占机并转返工。
- 返工须由另一人复测；连续两次合格且两次相隔满 4 小时才能放行。
- 温度或车速更正后：旧稿保留可查，旧放行立即失效，按新工艺重新计算（新稿首检合格可直接放行）。
- 机位、队列（FIFO）、履历全部由同一条事件流归约得到，刷新后保持一致；支持多标签页同步。

## 技术栈

React 19 + Vite + TypeScript，无后端，数据存于浏览器 localStorage（键 `heat-set-release-console:v1`）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62012。履历面板提供“重置演示数据”按钮，可恢复内置演示场景（返工中、排队待位、已放行后工艺更正失效、整单退回）。
