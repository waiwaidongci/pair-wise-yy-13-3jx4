# hxyfront-62012 热定型机位放行台

由染整小样页扩展的热定型机位放行台，管理小样从登记上机、初检判定、返工复测到放行的全过程。

## 规则

- 同一小样只占一台机；重复或并发登记沿用最早结果，不重复占机。
- 登记须包含温度、车速、门幅（标准/实测）、纬斜，缺项整单退回并留档。
- 门幅偏差超过 2%、纬斜超过 ±3cm 或手感低于 3 级：继续占机并转返工。
- 返工须另一人复测；连续两次合格且两次间隔满 4 小时才放行。
- 温度或车速更正后旧放行失效、按新参数重算，更正旧稿保留。
- 机位释放后等待队列中最早登记的单自动补位；刷新后机位、队列、履历一致恢复。

## 代码结构（规则、存档、界面各自成文件）

- `src/heatReleaseRules.ts`：规则引擎（纯函数：登记、初检、复测、更正、排队补位）。
- `src/heatReleaseStore.ts`：存档（localStorage 持久化 + 演示数据）。
- `src/HeatReleaseConsole.tsx`：界面（机位看板、登记表单、等待队列、放行管理、履历）。
